# Uso pedagógico
El paquete permite trabajar sin esperar insumos empresariales. Acompañen decisiones; no exijan todas las funcionalidades. La guía, los datos, los parámetros, las plantillas y el código son editables.

## Observar durante la prueba
- Las cifras tienen cliente y corte trazables; no se suman USD y COP directamente.
- Se excluyen anuladas, se controla el cruce de tablas y se reconoce que compras no equivale al costo de cada venta.
- El equipo distingue regla, predicción y recomendación humana.
- El modelo se compara temporalmente; una regresión no tiene por qué ganar en todas las métricas. En esta ejecución tiene mayor exhaustividad y menor precisión que la regla base, con muchos falsos positivos: esto debe discutirse.
- Se muestra al menos una prueba observada y una mejora derivada.

## Casos para conversación con otro equipo
1. ¿Por qué elegiste ese cliente para seguimiento?
2. ¿Qué cambia si cliente frío pasa de 90 a 120 días?
3. ¿Qué pasa con una compra anulada o una tasa ausente?
4. ¿Puedes demostrar que tu predicción no vio el futuro?
5. ¿Qué información pedirías a la empresa antes de usarlo realmente?

Los controles técnicos fueron ejecutados con Python del entorno de preparación. No se ha verificado una integración con servicios externos ni la aceptación de las reglas por la empresa.
